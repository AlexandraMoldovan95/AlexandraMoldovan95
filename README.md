## What support gave me

Years of root-causing real production issues - reading logs, reproducing edge cases under time pressure, writing reports precise enough for someone else to act on without re-doing the investigation - is most of what QA actually is, just without the title. The shift now is extending that same instinct into the code itself: writing it, testing it, and shipping it, with an AI coding agent as the practical tool for doing that as a career-changer rather than a four-year detour.
